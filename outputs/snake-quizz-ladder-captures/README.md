# Snake Quizz Ladder — live gameplay captures

Captured from the open Unity Editor against the existing healthy Docker staging API at localhost:3099. Resolution: 1080 × 1920.

- lobby.png: strongest overview, after claiming the local daily reward.
- board.png: actual server-backed match, with dice rolls and pawn movement verified during the session.
- customization.png: reference capture only; contains test catalog names and unfinished layout.

These are unretouched work-in-progress captures. The board includes white snake rendering and placeholder UI text. No quiz popup was reached during the sampled turns. Do not describe these images as a finished demo or polished release.

The local PortfolioDemo account was used. Match progress and a daily reward claim were saved to the Docker staging database. Unity Play Mode was stopped and the original development server URLs restored afterward. Docker was left running. The Unity Pipeline package installed for Editor control remains in Packages/manifest.json and packages-lock.json.

The portfolio gallery has not been changed to publish these captures.
